# 🎲 Projeto WebDesign — Plataforma de RPG

Este site é uma ferramenta digital desenvolvida para servir como assistente em partidas de RPG de mesa. O objetivo principal do projeto de WebDesign é modernizar a experiência dos jogos, substituindo as fichas de papel, borrachas e canetas por um sistema automatizado que elimina a necessidade de fazer contas de cabeça no meio da sessão.

O site foi construído dividindo-se em duas identidades visuais: uma interface escura no estilo painel (*dashboard*) para gerenciar as ferramentas, e uma interface clara e organizada que simula o preenchimento de uma ficha de papel clássica de forma limpa.

---

## 🛠️ O Ecossistema do Sistema

O funcionamento do site é baseado em quatro pilares integrados:

1. **Automação de Personagens (Criador de Fichas):** Uma área com formulários estruturados para montar o personagem do zero. O sistema organiza os campos biográficos, tabelas de atributos complexas (como Força, Destreza e Inteligência) e blocos textuais dedicados para magias e itens.
2. **Agilidade no Jogo (Rolador de Dados):** Um simulador integrado para rolar dados virtuais. O usuário define a quantidade de dados e o formato das faces (d4, d6, d8, d12, d20) e o sistema faz o sorteio matemático gerando o somatório total na hora.
3. **Organização Central (Painel de Fichas):** Uma central privada que guarda todos os heróis que você já criou, permitindo consultar os dados rapidamente durante a partida, além de oferecer opções para editar ou excluir fichas antigas.
4. **Acervo Comunitário (Biblioteca Pública):** Uma aba que exibe personagens criados por outras pessoas da comunidade. Funciona como um banco de ideias para inspiração, permitindo clonar modelos prontos direto para o seu painel.
